This a command line prompt tool.

------------How to run---------------
* open command prompt in file location
* run command "pip install rich"
* run command "python main.py"
--------------------------------------

---------Features--------------------
* Strong Random Password Generator
* Password Strength Checker + Crack Time Estimation
* SHA-256 Hash Generator
* Basic Port Scanner  (This one is dependant upon windows firewall and a timeout feature. it still needs some work)
